Empty states

Give people a clear next step when a collection has no content.

When to use

Use an empty state when someone opens a collection for the first time, clears its last item, or applies filters that return no results.

First use

Explain what belongs in the collection and offer one action that helps someone get started.

No matching results

Describe the result without blame and offer a way to adjust or clear the current filters.

Content guidance

  • Use a short, specific heading that describes the current state.
  • Explain the next step in one sentence.
  • Label the primary action with a verb and the item it affects.
  • Keep errors separate from a genuinely empty collection.

Accessibility

Keep the heading in the page hierarchy and the next action reachable by keyboard. Do not rely on an illustration alone to communicate why the collection is empty.
